# Fiat exchange rates

Use `exec` and `curl` for a current or historical fiat-currency rate or conversion. Identify base, quote, and optional amount; ask a concise clarification if terms such as “dollar” or “peso” are ambiguous. Use uppercase ISO 4217 codes. Query Frankfurter v2 without an API key, normally `curl -fsS --max-time 15 "https://api.frankfurter.dev/v2/rate/EUR/USD"`; add `?date=YYYY-MM-DD` for historical rates. Multiply the returned rate by the amount for a conversion; otherwise report one base unit. Include the returned rate date and direction, since the latest reference rate can be from a prior business day. Make one narrow request where possible and explain API failures rather than inventing values. Frankfurter has reference rates, not real-time tradable quotes; do not use it for crypto, stocks, cash spreads, card/bank rates, intraday trading, or general currency explanations.
